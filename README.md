# Thalisson Prata

Landing page premium da Thalisson Prata, criada em React + Vite e publicada automaticamente no GitHub Pages.

## Site público

Após o workflow do GitHub Actions concluir, acesse:

https://snuffyn.github.io/thalisson-prata/

## Desenvolvimento local

```bash
pnpm install
pnpm dev:static
```

O projeto usa uma direção visual editorial, com foco em joias de prata 925, atendimento pelo WhatsApp e experiência mobile-first.

## Build

```bash
pnpm build:static
pnpm check
```

O workflow em `.github/workflows/deploy-pages.yml` publica automaticamente cada alteração enviada ao branch `main`.
